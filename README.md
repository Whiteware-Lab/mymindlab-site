# MyMindLab

Canale pubblico di distribuzione di MyMindLab per Android.

[Scarica MyMindLab](https://whiteware-lab.github.io/mymindlab-site/)

Questo repository ospita esclusivamente il sito e gli APK firmati. Il codice sorgente dell’app e tutti i dati degli utenti non sono pubblicati qui.

Gli aggiornamenti sono proposti all’avvio dell’app e installati dopo la conferma dell’utente su Android.
